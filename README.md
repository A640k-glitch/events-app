# Event Management Platform

I built this project to streamline event discovery, pass reservation, and corporate briefing requests. It provides an intuitive platform where users can explore upcoming events, choose pass tiers (such as Free, Pro, or Team passes), view event schedules, and manage their event dashboard in real time.

## Tech Stack

Here is the tech stack I am using to build and power this application:

- **Framework**: Next.js 16 (App Router) & React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS (v4) & PostCSS
- **Animations & Effects**: Framer Motion & Canvas Confetti
- **Icons**: Lucide React
- **Utilities**: `clsx` & `tailwind-merge`
